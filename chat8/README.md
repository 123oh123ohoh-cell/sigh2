# chat8

A modern fullstack chat application inspired by https://github.com/alamorre/fullstack-chat.git

## Features
- Node.js/Express backend
- React frontend
- Socket.IO real-time messaging
- MongoDB storage
- JWT authentication
- User profiles, rooms, DMs, presence, and message history

## Structure
- `client/` — React frontend
- `server/` — Node.js/Express backend
