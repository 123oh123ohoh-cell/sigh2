# Migration Guide

All files have been reorganized into dedicated folders by type. Please move your files as follows:

- Move all *.html files to html/
- Move all *.css files to css/
- Move all *.js files to js/
- Move all *.json files to json/
- Move all *.md files to md/
- Move all *.jpg files to jpg/
- Move all *.png files to png/
- Move all *.bat files to bat/
- Move all database files (*.db) to db/
- Move all images to img/ (except jpg/png)
- Move all scripts to scripts/
- Move backend, controllers, models, routes, server folders as is
- Move all public assets to public/
- Move all vendor, fonts, themes, utils folders as is
- Move all pug templates to pug/

Update all file references in your code to match the new structure.
