# Folder Structure

- html/: HTML files
- css/: CSS files
- js/: JavaScript files
- json/: JSON files
- img/, jpg/, png/: Images
- md/: Markdown files
- db/: Database files
- bat/: Batch scripts
- scripts/: Miscellaneous scripts
- backend/, controllers/, models/, routes/, server/: Backend/server code
- public/: Public assets
- vendor/, fonts/, themes/, utils/: Supporting assets
- pug/: Pug templates
- readme/: Documentation
